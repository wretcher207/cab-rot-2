# Cab Rot

> Kill the wasp nest. Keep the teeth.

A focused dynamic harshness controller for high-gain amp-sim guitars. Removes 2 kHz–12 kHz fizz without neutering pick attack. Six modes (5150 / Recto / HM-2 / Djent / Blackened / Sludge), four-band detection, transient-protected reduction.

Dead Pixel Harmonix. JUCE 8 / VST3 / AU.
